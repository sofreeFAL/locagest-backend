👥 Rôles et Accès

ADMINISTRATEUR:

  • Se connecte avec identifiants prédéfinis
  • Gère TOUTE l'application
  • Crée les fiches clients
  • Crée les contrats de location

CLIENT:

  • N'a PAS de compte dans le système
  • Ne se connecte pas
  • Est géré par l'administrateur
  • Donne juste ses infos à l'agence

http://localhost:8080/auth/login

Body (JSON):

Réponse: Token JWT à utiliser dans les headers des requêtes suivantes

📅 Gestion des Locations

POST Créer une location Auth Required
http://localhost:8080/locations
{ "clientId": 2, "vehiculeId": 3, "dateDebut": "2025-01-15", "dateFin": "2025-01-17" }
GET Liste des locations Auth Required
http://localhost:8080/locations
GET Recherche par statut Auth Required
http://localhost:8080/locations/search?statut=EN_COURS

Statuts disponibles: EN_COURS, TERMINE, ANNULE

GET Historique des locations Auth Required
http://localhost:8080/locations/historique
GET Voir les détails d'une location Auth Required
http://localhost:8080/locations/{id}

Description: Récupère les informations complètes d'une location spécifique

PUT Modifier une location Auth Required À VENIR
http://localhost:8080/locations/{id}

Description: Permet de modifier les informations d'une location existante

DELETE Supprimer une location Auth Required À VENIR
http://localhost:8080/locations/{id}

Description: Supprime une location de la base de données

PUT Annuler une location Auth Required
http://localhost:8080/locations/{id}/annuler

Description: Change le statut de la location à "ANNULE"

Effet: Le véhicule redevient disponible, le statut passe à ANNULE
PUT Démarrer une location Auth Required À VENIR
http://localhost:8080/locations/{id}/demarrer

Description: Démarre officiellement une location (statut passe à EN_COURS)

Effet: Marque la location comme active, le véhicule devient indisponible
PUT Retour véhicule Auth Required
http://localhost:8080/locations/{id}/retour

Description: Enregistre le retour du véhicule et termine la location

Effet: Le statut passe à TERMINE, le véhicule redevient disponible
PUT Prolonger une location Auth Required
http://localhost:8080/locations/{id}/prolonger

Description: Étend la durée d'une location en cours

Body (JSON):

{ "nouvelleDateFin": "2025-01-25" }
Effet: La date de fin est mise à jour, le prix total est recalculé

📄 Gestion des Contrats

ℹ️ Informations sur les Contrats

Lors de la création d'un contrat :

  • On sélectionne une location existante
  • Le numéro de contrat est généré automatiquement
  • Le statut et la date de création sont automatiques
POST Créer un contrat Auth Required
http://localhost:8080/contrats

GET Liste des contrats Auth Required

http://localhost:8080/contrats/{id}

http://localhost:8080/contrats/{id}/pdf
PUT Modifier un contrat Auth Required

DELETE Supprimer un contrat Auth Required
http://localhost:8080/contrats/{id}
